Fica salva só neste navegador. Alternativa: crie um arquivo .env com GOOGLE_MAPS_API_KEY=sua_chave.

Como conseguir a chave (5 minutos)
  1. Acesse console.cloud.google.com e crie um projeto.
  2. Ative o faturamento (o Google oferece uso gratuito mensal; você só paga se passar da cota).
  3. Em "APIs e serviços → Biblioteca", ative Places API (New).
  4. Em "Credenciais → Criar credenciais → Chave de API", copie a chave e cole acima.
  5. Recomendado: restrinja a chave à Places API e defina um limite de cota diário para não ter surpresa na fatura.
